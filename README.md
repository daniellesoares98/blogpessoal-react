# 📝 Blog Pessoal | Full Stack

Aplicação Full Stack de um **Blog Pessoal**, desenvolvida individualmente durante o Bootcamp Java Full Stack da Generation Brasil.

O projeto foi construído de forma progressiva ao longo do curso. Inicialmente, foi desenvolvida a API utilizando **Java e Spring Boot** e, posteriormente, a aplicação ganhou uma interface desenvolvida com **React e TypeScript**, integrando Front-end e Back-end.

---

## 💻 Sobre o projeto

O Blog Pessoal é uma aplicação que permite aos usuários criarem uma conta, realizarem login e compartilharem postagens organizadas por temas.

O projeto foi utilizado durante o bootcamp para aplicar, de forma prática, diferentes conceitos de desenvolvimento Full Stack, acompanhando a evolução dos conteúdos de Back-end e Front-end.

Este repositório contém a implementação do **Front-end da aplicação**, responsável pela interface e pela comunicação com a API REST desenvolvida anteriormente.

---

## ✨ Funcionalidades

- Cadastro de usuários
- Login e autenticação
- Visualização do perfil
- Atualização de perfil
- Listagem de postagens
- Cadastro de postagens
- Edição de postagens
- Exclusão de postagens
- Listagem de temas
- Cadastro de temas
- Edição de temas
- Exclusão de temas

## 🔗 Integração Full Stack

O projeto foi desenvolvido em duas etapas principais:

**Back-end**

`Java + Spring Boot` → desenvolvimento da API REST e regras da aplicação.

**Front-end**

`React + TypeScript` → desenvolvimento da interface e integração com a API.

### Fluxo da aplicação

`React + TypeScript` → `Axios` → `API REST` → `Java + Spring Boot` → `Banco de Dados`

---

## 📚 Contexto

O Blog Pessoal foi desenvolvido individualmente ao longo do **Bootcamp Java Full Stack da Generation Brasil**.

Durante o módulo de Back-end, o projeto foi utilizado para colocar em prática os conceitos relacionados ao desenvolvimento de APIs.

Posteriormente, durante o módulo de Front-end, a aplicação foi retomada para a construção da interface e integração com o Back-end, permitindo acompanhar na prática o funcionamento das diferentes camadas de uma aplicação Full Stack.
